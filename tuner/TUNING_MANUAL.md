# ♟️ 西洋棋引擎 V2 調參詳細說明書 (Tuning Manual)

本說明書旨在引導開發者如何使用基於 **SPSA (Simultaneous Perturbation Stochastic Approximation)** 演算法的調參系統，針對 V2 Numba 引擎的評估參數進行自動化優化。

---

## 📋 快速啟動 (Quick Start) 清單

如果您已經準備好 PGN 檔案，請直接執行以下三步：

1.  **數據準備**：
    ```bash
    python tuner/generate_training_data.py --pgn your_games.pgn --min-elo 2400 --max-cp 200 --min-move 12
    ```
2.  **轉換格式**：
    ```bash
    python tuner/preprocess_data.py
    ```
3.  **啟動調參**：
    ```bash
    python -m tuner.tuner --iter 5000 --batch-size 16384 --alpha 30000 --c 2.0
    ```

---

## 🛠️ 第一階段：數據生成 (Data Generation)

高品質的數據是調參成功的關鍵。`generate_training_data.py` 是整個流程最重的一環。

### 1. 核心邏輯
-   **連續標籤 (Continuous Labels)**：不同於傳統的勝 (1)、平 (0.5)、負 (0)，我們將 Stockfish 的評分 (Centipawns) 轉為 Sigmoid 值。這能讓系統學習到「+50cp 的局面比 +30cp 好」，而不僅僅是「這兩局都是平局」。
-   **智慧篩選**：自動跳過戰術局面（如已有吃子、將軍），只對穩定的靜態局面進行學習。

### 2. 關鍵參數說明
*   `--min-elo 2400`：(建議) 只學習特級大師等級的對局，排除低分段的錯誤邏輯。
*   `--max-cp 200`：(建議) 排除已有一方勝勢的局面。在 ±2.0 分之內的局面最具有爭議性，也最需要精確的評估。
*   `--min-move 12`：(建議) 跳過開局定式，直接進入中局。
*   `--stockfish-depth 10`：分析深度。設為 10-12 可以在處理速度與評分準確度之間取得平衡。

---

## 📊 第二階段：數據預處理 (Preprocessing)

為什麼要預處理？為了 **速度**。

執行 `preprocess_data.py` 會將 JSONL 文字檔轉為 NumPy `npz` 二進位格式。
-   載入速度提升 **>50 倍**。
-   訓練時不再需要磁碟讀取，全部駐留在記憶體中，這讓 Mini-batch 計算變得極快。

---

## 🚀 第三階段：SPSA 調參 (The Tuner)

SPSA 是一種隨機梯度下降演算法，特別適合處理西洋棋引擎這種「參數極多且無法求導」的系統。

### 1. 執行參數詳解
*   `--iter`：迭代次數。建議初步嘗試 5000 次，穩定後可執行 20000 次以上。
*   `--batch-size`：**(重要)** 每次迭代抽取的樣本數量。
    -   `16384` 或 `32768`：最佳平衡點。速度極快且梯度估算穩定。
    -   不設此參數：使用全量數據。最準，但每一步都會非常慢（適用於微調階段）。
*   `--alpha` (學習率)：控制參數更新的步長。
*   `--c` (擾動幅度)：控制探索的範圍。

### 2. 約束系統 (Constraint Manager)
系統會自動強制執行以下邏輯，防止參數「壞掉」：
-   **國王價值固定**：國王的 MG/EG 價值永遠鎖定在 0，不會隨意漂移。
-   **材質遞增**：確保 `兵 < 馬 < 象 < 車 < 后` 的邏輯不被打破。
-   **獎勵/懲罰合法性**：所有 Bonus 必須 >= 0，Passed Pawn 獎勵必須隨橫排 (Rank) 遞增。

## 📈 第四階段：結果整合 (Integration)

訓練過程中，當 `Best MSE` 更新時，系統會自動將當前最優參數寫入 `tuner/tuned_constants.py`。

### 應用步驟：
1.  打開 `tuner/tuned_constants.py`。
2.  複製當中的 Python 字典內容。
3.  貼回引擎主目錄下的 `chess_engine/constants.py` 中對應的常數位置。
4.  重新編譯 (Numba 會自動處理) 並進行對局測試 (SPRT)。

## 💡 專家建議：穩定性與調參技巧 (Stability Tips) ✅

如果您發現調出來的數值兩極化或是漂移（例如兵的價值變得很低），這通常是因為 **缺乏基準錨點** 或 **學習率過高** 導致的。

### 1. 確保基準錨點 (The Pawn Reference)
在西洋棋評估中，100 分（一個兵）是所有價值的基準。如果讓「兵」也隨機漂移，整個評分尺度會產生縮放誤差（例如所有值都除以 10，MSE 雖然會下降，但數值已失去意義）。
*   **引擎更新**：我已在 `tuner.py` 中將 **Pawn MG 鑽定在 100**，**Pawn EG 鎖定在 120**。這能確保所有其他參數（馬、象、位置分）都以「兵」為共同單位。

### 2. 推薦的超參數 (Hyperparameters)
對於 **10 萬筆以上** 的數據集，建議使用以下配置以獲得平滑的結果：
*   `--alpha 5000`：更溫和的學習率（初始步長約 1.5cp），防止參數在迭代中產生劇烈震盪。
*   `--c 1.0`：較小的擾動，適合在目前已有的基礎上進行「微調」。
*   `--batch-size 32768`：較大的 Batch 能提供最穩定的梯度方向。

### 3. 如何處理「數值異常」？
*   **負值問題**：有些 Bonus 如果調成負值，可能代表該邏輯在您的引擎中與 SF 衝突。
*   **地板價限制**：我已在 `tuner.py` 中為馬、象、車、后加上了「地板價」，防止它們變得比兵還便宜。

---

### 6. 常見問題排解 (FAQ)
*   **❓ 為什麼 MSE 下降慢？**：可以嘗試逐漸調高 `--alpha`。
*   **❓ 調出的參數可以直接用嗎？**：務必檢查 `tuned_constants.py` 是否有異常值。正常的權重應該是「平滑」且符合棋理的。
