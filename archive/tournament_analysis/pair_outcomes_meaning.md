# 對局對 (Match-Pair) 九宮格賽果之統計意義解析

採用「同開局交換執色」的對局對測試時，區分「白方賽果」與「黑方賽果」能更精確地掌握引擎的技術特性。以下是九種賽果組合的詳細解析（以 v2 引擎為視角）：

### 1. 雙勝 (WW - Win White, Win Black)
*   **意義**: **全面統治**。
*   **解析**: 無視執色優勢，在該開局主題下展現了絕對的實力差距。

### 2. 白勝黑和 (WD - Win White, Draw Black)
*   **意義**: **優勢穩健**。
*   **解析**: 成功利用了白方的先手優勢奪勝，且在執黑時展現了極其穩固的防禦。這是高水準引擎最理想的勝勢模式之一。

### 3. 白勝黑負 (WL - Win White, Loss Black)
*   **意義**: **開局執色高度不平衡 (Sharp/Unbalanced White)**。
*   **解析**: 白方具備壓倒性優勢，或該開局對黑方極端不友善。雙方在該位置下都傾向於只有持白方能取勝。

### 4. 白和黑勝 (DW - Draw White, Win Black)
*   **意義**: **後手反擊能力優異**。
*   **解析**: 在執黑時能強力反擊奪勝，但在執白時未能將先天優勢轉化為勝利。這可能暗示引擎在「主動進攻」與「防守反擊」的評估上存在微小失衡。

### 5. 雙和 (DD - Draw White, Draw Black)
*   **意義**: **動態平衡 / 頂尖對抗**。
*   **解析**: 雙方防禦體系皆無漏洞，是衡量引擎防守「韌性」的指標。

### 6. 白和黑負 (DL - Draw White, Loss Black)
*   **意義**: **防禦漏洞 / 技術劣勢**。
*   **解析**: 執白時僅能勉強守和，執黑時則迅速崩盤。通常出現在評估函數對於殘局或複雜戰術位置的權重不足時。

### 7. 白負黑勝 (LW - Loss White, Win Black)
*   **意義**: **極端的黑方優勢 (Sharp/Unbalanced Black)**。
*   **解析**: 罕見情況。表示該開局可能是一個著名的「黑優開局」，或您的引擎在該主題下持黑的演算法效率遠高於持白。

### 8. 白負黑和 (LD - Loss White, Draw Black)
*   **意義**: **嚴重執白缺陷**。
*   **解析**: 執白卻輸球，反而是執黑時守平。這是一個強烈的警訊，暗示引擎在處理白方進攻節奏或時間分配上存在重大問題。

### 9. 雙敗 (LL - Loss White, Loss Black)
*   **意義**: **系統性潰敗**。
*   **解析**: 該開局主題完全被對手破解，或存在嚴重的搜尋盲區。
